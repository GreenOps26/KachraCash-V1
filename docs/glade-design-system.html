Glade Design System

A grounded visual language for dashboards people check every day.

Glade pairs a deep pine-green palette with a warm cream canvas — built from the dashboard, wallet and admin interfaces that inspired it. Every color, type style and component below is documented and ready to build with.

Pine and forest greens anchor the system; cream and sand carry the surfaces. Gold marks emphasis, coral marks risk. Click any swatch to copy its hex value.
